# chat-app
Welcome to My Awesome Chat App!
This app lets you talk to your friends and family easily. It's built using some cool technologies to make it fast and smooth.

What It Does
Send Messages: You can type messages and send them to other people who have the app.
See Who's Online: You can see which of your friends are using the app right now.
Have Group Chats: You can create groups to chat with lots of people at the same time.
Share Pictures: You can send photos to your friends in chats.
Get Notifications: The app will tell you when you get a new message so you don't miss anything.
How to Use It
Sign Up: When you open the app for the first time, you'll need to create an account with your name and maybe an email or phone number.
Find Your Friends: You can search for your friends by their name or username.
Start Chatting: Tap on a friend's name to start a new conversation. Just type your message and hit send!
Create a Group: There should be a button or option to create a new group chat and invite your friends.
Send Pictures: Look for a button (usually a paperclip or a picture icon) in the chat to send photos from your phone.
Built With Awesome Tech
This app uses some great tools to make it work well:

Backend: The server that handles all the messages and users is built with Node.js.
Real-time Communication: We use WebSockets to make sure your messages are sent and received instantly.
Frontend (What you see): The part of the app you interact with is built using React and Vite, which makes it fast and responsive.
Looks and Style: The app's design is powered by Tailwind CSS, which gives it a modern and clean look.
Code Quality: We use ESLint to make sure our code is consistent and easy to understand.
